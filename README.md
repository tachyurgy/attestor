# Attestor

**Account-recovery assurance engine: ICAO 9303 MRZ validation weighed against blast radius.**

Live: **https://attestor.levelbrook.com**

## What this is

In account recovery the helpdesk is the vulnerability, not the software around it. An attacker
calls claiming to be a locked-out employee, applies time pressure, and the control is a human being who wants to
be helpful. Attestor models the replacement.

## Engineering notes

### Assurance weighed against blast radius

Evidence scores into an assurance ledger and is weighed
against what is being asked, so the same evidence flips between allow, step up and deny depending on whether the
request is a password reset or a privileged role grant. Verification is not a property of a person, it is a
property of a person plus what they want.

### Real ICAO 9303 TD3 MRZ parsing

Full check-digit validation including the 7-3-1 weight cycle,
A=10 through Z=35 letter mapping, and the composite digit spanning document number, birth date, expiry and
optional data. Verified against the canonical worked example (D23145890 gives 7).

### A tampered document that fails for a real reason

The tampered passport is generated by taking a
valid MRZ and changing one digit, so it fails arithmetically rather than via a hardcoded flag. It fails only the
composite check, which is exactly what happens when someone retypes one field of a real document and does not
recompute the composite.

### Capture-chain integrity is disqualifying, not subtractive

One session passes every biometric
check and is still denied, because the frames never came from a camera. Assurance signals are additive only
while you can trust the capture chain. An attacker running a virtual camera can manufacture unlimited passing
checks, so summing more of them proves nothing.

## Stack

Vanilla JavaScript, ICAO 9303 TD3 implementation, static hosting


## Running it

Static. Open `index.html`, or serve the directory:

```
python3 -m http.server 8000
```

## Honest scope

This is a focused engineering demo, not a production system. The data is synthetic and generated
locally so that the behaviour is reproducible. The reasoning, the arithmetic and the failure modes
are the point; the surface area is deliberately narrow.
